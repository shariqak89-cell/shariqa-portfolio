# Shariqa — Creative Digital Portfolio

A responsive, single-page portfolio for Shariqa, covering graphic design, websites, video production, AI workflows and selected client work.

## Included

- Embedded YouTube video portfolio with inline playback
- External “Open on YouTube” links for every video
- Client website links for DigiSparkX and Javed Press
- Responsive navigation and mobile layout
- Scroll progress indicator and reveal animations
- GitHub Pages-ready static files

## Publish

This site is plain HTML, CSS and JavaScript. It can be hosted on GitHub Pages, Netlify, Vercel or any standard static host.
